# Casablanca House Price Prediction

## Project Overview

This project uses Machine Learning to predict residential property prices in Casablanca, Morocco.

The objective is to build and evaluate a Random Forest Regression model using property characteristics and geographical information.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn
- Machine Learning
- Random Forest Regression

## Dataset

The project uses the Casablanca Housing dataset, containing property information such as:

- Number of rooms
- Bathrooms
- Land size
- Age_in_years
- Garage
- Property prices

## Project Workflow

1. Data loading and exploration
2. Feature selection
3. Handling missing values
4. Training and validation split
5. Baseline model development
6. Random Forest model training
7. Model evaluation
8. Data visualization

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Visualizations

The project includes:
- Actual vs Predicted House Prices
- Feature Importance

## How to Run

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python main.py
```
